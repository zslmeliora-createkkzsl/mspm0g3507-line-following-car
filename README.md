# MSPM0G3507 循迹小车

基于 **TI LP-MSPM0G3507 LaunchPad** 的八路灰度循迹小车：任意位置发车，按设定圈数跑完，自动停回发车点。控制部分全部手写 DriverLib，不依赖 SysConfig 生成的业务代码。

> 场地：1m × 1m 白底黑线正方形赛道，4 个直角弯为 1 圈。

---

## 功能

- **八路灰度循迹**：数字量读取，加权求黑线位置（0~7000，3500 居中），PID 差速控制左右轮。
- **直角弯识别**：连续 50ms 八路全黑才判定进入弯道，避免轮子打滑误判。
- **pivot 转弯**：绕内侧轮转（内侧轮停、外侧轮转），配合陀螺仪判角。
- **陀螺仪判角**：MPU6050 积分 Z 轴角速度，转过 70° 且黑线回到传感器中段才停转。
- **编码器回原点**：发车时用编码器记下"发车点到第一个弯"的距离，跑完圈数后自动走"整条边 − 这段距离"，任意位置发车都能停回原地。
- **记圈**：4 个直角弯记 1 圈，可设 1~5 圈。
- **按键**：PA25 设圈数（按几下闪几下），PB13 开始 / 暂停。
- **故障指示**：MPU6050 初始化失败时红灯闪错误码。

## 控制流程

```
上电 → 初始化（GPIO / PWM / UART0 / I2C0 + MPU6050 + 编码器）
     → 设圈数（按 PA25 1~5 下，闪对应次数；按 PB13 确认）
     → 每 10ms 循环：
          读 MPU6050 Z 轴角速度 → 积分得本轮转角
          读编码器 → 累计脉冲
          读八路灰度 → 加权位置
          ├ 连续 50ms 全黑 → 进直角弯，pivot 原地转
          │     转角 ≥ 70° 且黑线回中 → 结束转向，300ms 冷却
          ├ 全白丢线 → 低速直行找线
          └ 正常压线 → PID 差速循迹
     → 跑完 laps×4 个弯 → 回程走"整条边 − 发车点到第一个弯" → 停回发车点
```

**pivot 转弯分级减速**：< 50° 用 720，50°~68° 用 640，> 68° 用 560。

**回原点原理**：发车点到第一个直角弯的距离记为 d，跑完圈数后最后一个弯转完，再走 `边长 − d`，正好回到发车点（放哪都行，不用在边中点）。

## 参数（config.h）

| 参数 | 当前值 | 作用 |
|---|---|---|
| `SENSOR_ACTIVE_LEVEL` | 1 | 压黑线输出高；不跟线改 0 |
| `SENSOR_INVERT_ORDER` | 0 | 左右反了改 1 |
| `BASE_SPEED` | 480 | 直行基础 PWM |
| `MAX_SPEED` | 2400 | 单轮上限（12V 别超） |
| `TURN_SPEED_FAST` | 720 | 直角弯起步 |
| `TURN_SPEED_MID` | 640 | 直角弯中段 |
| `TURN_SPEED_SLOW` | 560 | 直角弯末段 |
| `PID_KP` | 0.40 | 回拽力度 |
| `PID_KI` | 0.0 | 未启用 |
| `PID_KD` | 0.3 | 抑制抖动；太大回正过冲 |
| `LINE_CENTER` | 3500 | 8 路加权位置中心 |
| `LOOP_PERIOD_MS` | 10 | 控制周期 |
| `ENCODER_PULSES_PER_CM` | 26 | 每厘米脉冲数（实测校准） |
| `EDGE_LEN_CM` | 100 | 场地边长（cm） |

PWM 周期 3200（32MHz / 3200 = 10kHz）。注意 `INIT_VAL_LOW` 配置下占空比 = `(period - 1 - CC) / period`，停车写 `CC = period - 1`。

编码器系数校准：如果停车**冲过头**，把 `ENCODER_PULSES_PER_CM` 调小；**没到发车点**就调大。公式：`新系数 = 100 × 当前系数 ÷ (100 ± 偏差cm)`。

## 编译与烧录

1. 安装 **CCS Theia 21.0.1** 与 **MSPM0 SDK 2.11.00.07**。
2. CCS 中 `Project → Import CCS Projects`，选择本仓库目录，导入 `line_following_car_LP_MSPM0G3507_nortos_ticlang`。
3. 编译（Build），USB 连 LaunchPad，XDS110 / SWD 烧录（Flash）。

> 工程没有 SysConfig 文件，外设初始化全在 `ti_msp_dl_config.c` 手写，改引脚时同步改 PINCM 宏。

## 使用步骤

1. **传感器校准**（模块断电保存，换场地/高度才重做）：上电等约 20s → 长按模块 KEY 进校准（红灯亮）→ 放黑线上按一下 KEY → 放白底上按一下 KEY → 红灯灭即成功。
2. **设圈数**：上电后按 PA25 几下（LED 闪几下），按 PB13 开始。
3. **运行**：跑完圈数自动回发车点停车；运行中按 PB13 暂停/继续。

### 调试串口

UART0（PA10，115200）每 100ms 打印一行：

```
S:00110000 P:3500 C:0 A:0 D:0
```

`S` 八路状态、`P` 加权位置、`C` 已过弯数、`A` 本次转角、`D` 回程累计脉冲（校准编码器用）。

### LED 错误码

MPU6050 初始化失败时程序停在此处闪灯：

| 闪烁 | 含义 |
|---|---|
| 1 下 | 写寄存器无应答（接线 / 供电 / 共地） |
| 2 下 | 读寄存器无应答 |
| 两组（高 4 位 + 低 4 位） | WHO_AM_I 值不对，闪的就是实际值 |

> 手上的模块 WHO_AM_I 返回 0x70（MPU6500），代码已放宽到 0x68/0x70/0x71/0x73。

## 踩过的坑

- **I2C 读寄存器必须先重复起始**：写完寄存器地址若发 STOP，芯片内部地址指针被清掉，再 START 读就取不到数据。
- **所有硬件等待都要加超时**：否则一个器件掉线就整机卡死。
- **陀螺仪量程太小会饱和**：±250°/s 在快速转向时积分角度偏小，改到 ±1000°/s。
- **边沿计数的 count 是计数范围**：设 0 会让计数器不计数（编码器读数一直是 0），要设大值（如 0xFFFF）。
- **丢线不要原地乱转**：车头方向本来是对的，低速直行更容易重新压线。

## 已知限制

- 编码器只接单相（A 相），测距测速够用，但测不了方向。
- 陀螺仪未做上电零偏标定，静止偏差会随时间累积。
- 直角弯判据与传感器阈值相关，换场地或改安装高度需重新校准。
